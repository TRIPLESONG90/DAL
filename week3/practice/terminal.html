DAL / WEEK 03 / COMMAND PRACTICE

파일을 찾아 읽어 보기

브라우저 안에서 동작하는 학습용 모의 셸입니다. 실제 SSH 연결이나 운영체제 명령은 실행하지 않습니다. 네트워크 연결 없이 사용할 수 있습니다.

강의로 돌아가기실습 기록지
learner @ dal-practice모의 환경
↑ / ↓ 이전 명령 · Ctrl+C 입력 대기 중단 · help 지원 명령 확인

연습 파일과 내용은 DAL에서 만든 예시입니다. Bandit 계정, 서버, 비밀번호와 연결되지 않습니다.

지원 범위pwd · whoami · hostname · ls · cd · cat · file · help · man · clear · exit
기본 경로, 따옴표, ls의 -a/-l/-la와 file의 * 패턴을 연습합니다. 실제 셸의 모든 문법과 기능을 구현한 환경은 아닙니다.
