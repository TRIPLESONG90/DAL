SSH

SSH: 다른 PC의 터미널에 접속

내 터미널에 입력한 글자가 원격 컴퓨터의 셸로 전달되고, 그 컴퓨터에서 실행한 결과가 돌아옵니다.

내 PC에서 입력

ls, cat readme 같은 명령 한 줄

SSH로 전달

암호화된 연결로 명령과 결과를 주고받음

원격 PC에서 실행

원격 PC의 셸이 명령을 실행해 그 컴퓨터의 파일·프로그램을 조작 · 결과는 내 화면에 표시

화면 전체가 아니라 글자만 오가므로, 멀리 있는 서버나 모니터가 없는 PC도 같은 방식으로 조작합니다. 필요한 것: 상대 PC의 SSH 서비스 · 접속 계정 · 작업 권한

LOCAL / REMOTE

접속 전후: 명령이 실행되는 컴퓨터

같은 터미널 창이지만, SSH 접속 후에는 원격 컴퓨터에서 명령이 실행됩니다.

접속 전 · 내 PC (Windows)
PS C:\Users\student> hostname
STUDENT-PC
접속 전 · 내 PC (Mac)
student@MacBook-Air ~ % hostname
MacBook-Air.local
접속 후 · 원격 서버
bandit0@bandit:~$ hostname
bandit
bandit0@bandit:~$ whoami
bandit0
bandit0@bandit:~$ pwd
/home/bandit0

프롬프트가 바뀌면 실행 위치가 바뀐 것 · hostname, whoami로 어느 컴퓨터의 어느 계정인지 확인 · 출력은 예시

AGENT CONNECTION

AI 에이전트 연결: 요청을 실행으로

LLM이 사용할 프로그램과 입력값을 구성하고, 실행 도구가 처리합니다.

역할예시
사용자 요청“원격 서버의 notes 폴더 목록을 보여줘.”
LLM / 명령 구성ls /home/learner/notes
TOOL / 명령 실행접속한 서버의 셸에서 명령 실행
결과 확인조회한 파일 목록으로 응답

LLM은 명령을 제안하고, 권한을 가진 도구가 실제로 실행합니다. 자연어 요청 → 명령 구성 → 권한·승인 확인 → 도구 실행 → 결과 검증. 경로와 명령은 설명용 예시입니다.
