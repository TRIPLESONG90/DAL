# DAL 3주차 강의 자료

이번 주에 전할 내용은 두 가지입니다.

1. **컴퓨터는 텍스트 기반의 터미널에서 모두 조작할 수 있습니다.** 폴더 열기·파일 보기·프로그램 실행처럼 마우스로 하던 일을 명령 한 줄로 합니다.
2. **텍스트로 원격 접속하면 그 PC의 터미널에 들어가 조작할 수 있습니다.** SSH로 접속하면 같은 터미널 창에서 입력한 명령이 원격 컴퓨터에서 실행됩니다.

OverTheWire의 Bandit은 명령만으로 원격 서버의 파일을 탐색하며 두 번째 내용을 직접 해 보는 실습입니다. LLM의 출력도 텍스트이므로, 마지막에 자연어 요청 → 명령 한 줄 → 도구 실행 흐름으로 Agent와 연결합니다.

## 시작

상위 폴더의 [week3.html](../week3.html)을 브라우저에서 엽니다. 강의 화면과 자체 연습기는 인터넷 없이 동작합니다. 실제 Bandit 접속과 공식 문제 열기는 인터넷 연결이 필요합니다.

- 방향키 / PageUp·PageDown: 이전·다음
- O: 목차 / F: 전체 화면 / Home·End: 처음·마지막
- 하단 `인쇄`: 브라우저 인쇄 또는 PDF 저장
- 슬라이드 1~17 · 12번: 10분 휴식 타이머

## 지난주·다음 주와 연결

- **지난주(2주차):** LLM은 명령어를 생성할 수 있어도 명령을 실제 실행하지는 않습니다. 예측 모델과 실행 엔진을 구분했습니다.
- **이번 주(3주차):** Shell은 명령을 해석하고 프로그램을 실행하며 SSH는 원격 컴퓨터의 작업 환경에 접속하게 합니다.
- **다음 주(4주차):** 내 업무 데이터를 DB에 구조화하고 CRUD 기능을 API로 제공해 AI가 사용할 수 있는 기반을 만듭니다.

핵심 확인 질문: **"AI가 명령을 적는 것과 실제 실행하는 것 사이에는 무엇이 필요할까요?"**

## 수업 전에

1. 참여자 PC의 터미널(Windows PowerShell 또는 Mac 터미널)에서 `ssh -V`로 클라이언트를 확인합니다. Mac은 기본 포함, Windows는 선택적 기능의 OpenSSH Client가 필요합니다.
2. 강사는 **같은 수업 네트워크**에서 `bandit.labs.overthewire.org:2220`으로 실제 SSH 로그인을 확인합니다. 사내망 접속 가능 여부는 별도 확인이 필요합니다.
3. 접속할 서버와 최초 호스트 키 지문을 신뢰할 수 있는 경로로 확인합니다. 키 변경 경고는 임의로 무시하지 않습니다.
4. 공식 [Level 0](https://overthewire.org/wargames/bandit/bandit0.html)에서 최신 시작 정보를 확인합니다.
5. 네트워크가 막히면 [자체 연습기](practice/terminal.html)로 파일 탐색을 연습합니다. 실제 SSH 접속은 별도 보충합니다.

```powershell
ssh -p 2220 bandit0@bandit.labs.overthewire.org
```

비밀번호 입력은 화면에 표시되지 않을 수 있습니다. 비밀번호는 공식 시작 페이지 또는 직전 단계에서 확인합니다. 실제 비밀번호를 공용 기록지, 저장소, AI 프롬프트에 넣지 않습니다.

## 기본 목표

기본 목표는 **bandit3 계정으로 로그인 성공**입니다. 접속이 지연되면 bandit1 로그인과 사용한 명령 설명을 먼저 완료합니다. 진도보다 실행 위치, 명령 선택 이유, 출력 해석을 확인합니다.

`worksheet.html`은 입력한 내용을 텍스트 파일로 내려받거나 이 브라우저에 저장할 수 있습니다. 브라우저 저장이 제한되는 환경에서는 내려받기를 사용합니다.
