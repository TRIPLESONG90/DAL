## 이번 주 반드시 이해할 차이

**LLM은 외부 프로그램의 실행 엔진이 아닙니다.** LLM이 `ls -la`라는 문자열을 생성해도 파일 목록이 조회된 것은 아닙니다. 모델 추론은 학습된 파라미터로 다음 출력을 계산하는 과정이며, 파일 접근·프로그램 실행에는 별도 실행 도구와 권한이 필요합니다.

수업 마무리 질문: **"LLM이 `ls -la`를 생성했는데 왜 실제 파일 목록은 나타나지 않을까요?"**

이 질문을 3주차의 CLI·Shell·SSH로 연결합니다. 4주차에는 업무 데이터를 CRUD·API로 제공하고 6~8주차에 도구·Skill로 연결합니다.

## 강의의 중심
사람이 함수 f의 구조와 가정(inductive bias)을 정하고, 학습 알고리즘이 데이터로 파라미터 θ를 조정한 다음, 학습한 함수로 새로운 입력 x의 결과를 예측합니다.

공통 원리 `ŷ = fθ(x)`를 먼저 설명하고, 선형회귀의 전체 과정, CNN 기반 이미지 분류, GPT형 Transformer 언어 모델의 다음 토큰 예측 순으로 연결합니다. 선형회귀는 실습과 같은 24개 데이터로 설계 → 손실 계산 → 학습 → 새 입력 예측을 이어 갑니다.

첫 실습은 직선 구조 안의 w와 b를 학습합니다. 기본값 w=b=0, 학습률 0.01의 자동 학습은 927회에서 멈추며 w≈1.94, b≈4.56, 손실≈4.16입니다. 새 입력 x=6의 예측은 약 16.2μm입니다. 고정 시드로 생성한 교육용 데이터입니다. 둘째는 고정 필터 계산을 관찰하며 실제 CNN 학습은 하지 않습니다. 셋째는 이미 학습한 언어 모델의 추론을 관찰하며 가중치를 다시 학습하지 않습니다.
