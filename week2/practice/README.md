## ① 경사하강법 — `gradient-descent.html`

파일을 더블클릭해 브라우저로 엽니다. 금형 사용 횟수(x)로 마모량(y)을 예측하는 직선 `y = w·x + b`를 찾습니다(예시 데이터).

1. **손으로 맞춰 보기** — w, b 슬라이더를 움직여 손실을 최대한 줄여 봅니다. 빨간 점선이 오차입니다.
2. **자동 학습** — 학습률 0.01로 "자동 학습"을 누르고, 손실 그래프가 내려가는지 봅니다.
3. **학습률 바꾸기** — 가장 작게 하면 아주 느리고, 0.035 이상이면 손실이 튕겨 커집니다(발산).
4. **비교** — 손으로 찾은 w, b와 자동으로 찾은 값(w ≈ 1.92, b ≈ 4.72)을 비교합니다.

## ② CNN 필터 — `cnn-filter.html`

파일을 브라우저로 엽니다. 예시 부품 이미지(판재·원형 부품·삼각형·흠집 하나)가 나옵니다.

1. **필터 바꿔 보기** — 세로 경계, 가로 경계, 모든 경계, 흐리게, 선명하게
2. **이미지 클릭** — 그 자리의 3×3 조각과 필터를 곱하고 더하는 계산이 아래에 나옵니다.
3. **ReLU · 풀링** — 켜고 끄며 CNN 한 층이 하는 일을 봅니다.
4. **숫자 직접 바꾸기** — 대각선 흠집만 밝게 보이는 필터를 만들어 봅니다. 예: `-1 -1 2 / -1 2 -1 / 2 -1 -1` (왼쪽 아래 → 오른쪽 위 방향)
5. **내 사진** — "내 사진 열기"로 다른 이미지에도 적용해 봅니다. 사진은 이 PC 안에서만 처리됩니다.

## ③ 다음 단어 확률 — `next_token.py`

VS Code 터미널(PowerShell)에서 실행합니다. 사내 Ollama 서버(`25.25.25.201:11435`, gemma4:31b)에 연결하므로 사내망(VPN)에 있어야 합니다.

```powershell
cd "$HOME\Documents\DAL\week2\practice"

# 다음 토큰 후보와 확률 (3토큰까지)
python next_token.py "오늘 아침 출근길에 비가 와서 나는" --steps 3

# 거의 반반인 경우
python next_token.py "대한민국의 수도는" --steps 2

# temperature를 높여 세 번 생성 → 매번 다른 답
python next_token.py "우리 팀의 다음 프로젝트 이름은" --temperature 1.2 --runs 3
```

확인할 점:

- 1등 후보는 몇 %이고, 2등과 얼마나 차이 나는지
- `␣`(띄어쓰기)가 들어간 토큰 — 단어가 아니라 **단어 조각**으로 나뉜다는 것
- temperature 0은 항상 같은 답, 높이면 낮은 확률의 후보도 뽑혀 답이 달라진다는 것
- 내 업무 문장으로도 해 보기 (예: "절곡기 불량의 주요 원인은")

서버 주소를 바꾸려면 환경변수 `OLLAMA_URL`, 모델은 `OLLAMA_MODEL`로 지정합니다.
