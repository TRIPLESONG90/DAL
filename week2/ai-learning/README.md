# DAL 2주차 강의 자료

대상은 개발 경험이 없는 사무직 직원입니다. 간단한 직선식으로 학습 원리를 본 뒤, 모델 구조가 바뀌는 흐름을 따라갑니다.

1. **AI 모델은 어떻게 배우는가** — 선형회귀의 데이터·모델·loss·학습·추론을 익히고 CNN → RNN → Transformer로 계산 구조를 넓혀 보기
2. **LLM은 왜 Text to Text 모델인가** — 다음에 올 말 맞히기, 문맥, 토큰, 한 조각씩 이어 쓰기, 그럴듯함과 사실의 차이
3. **글만 쓰는 LLM이 어떻게 일을 하게 되는가** — 프로그램(하네스), 도구 목록, 정해진 양식의 요청서, 결과 되돌려 주기, Agent, 확인과 권한

## 모델 설명 장면
5~9장은 같은 설비 데이터로 선형회귀의 다섯 단계를 보여 줍니다. 6장은 기울기와 y절편을 움직이고, 7장은 점을 눌러 오차를 확인합니다. 5·8·9장과 뒤의 LLM 장면은 슬라이드를 열면 자동으로 재생되며 **처음부터 / 일시정지** 버튼으로 조작합니다.

12장은 축소한 사진 한 장을 처리하는 작은 CNN에서 합성곱·역전파·가중치 수정을 직접 계산합니다. 은닉층을 누르면 필터를 확대하고, **다음 단계**로 계산을 천천히 진행할 수 있습니다. 6회 수정 후 결과를 유지하며, **처음부터**로 재시작합니다. 다양한 사진에 대한 일반화 성능을 보여 주는 실험이 아니라 한 학습 과정의 설명 예제입니다.

| 슬라이드 | 장면 |
|---|---|
| 4 | 지난주 Agent → 선형회귀 → CNN·RNN·Transformer → LLM → Agent 경로 |
| 5~9 | 선형회귀 — 데이터 → 직선 설계 → loss → 학습 → 추론 |
| 10 | CNN ① — 입력 이미지 → 은닉층의 특징 텐서 → 출력층 |
| 11 | CNN ② — Classification 점수 벡터 · Detection 상자 좌표 · Segmentation 픽셀 텐서와 시각화 |
| 12 | CNN ③ — 작은 CNN의 순전파·역전파·가중치 수정, 필터 확대와 loss 그래프 (자동 재생·다음 단계) |
| 13 | RNN ① — 같은 셀로 단어를 읽으며 기억 상태 넘기기 |
| 14 | RNN ② — 생성한 단어를 다음 입력에 넣어 이어 쓰기 |
| 15 | 모델 설계의 Inductive bias → 데이터로 가중치 학습 → 고정 후 추론, LLM의 다음 토큰 확률 예측 |
| 16 | Transformer — Q·K로 attention map을 만들고 비중에 따라 V를 모아 다음 토큰 예측 |
| 17 | 선형회귀와 LLM — 학습 데이터·예측·정답 비교·수정의 공통 순서 |
| 19 | LLM 학습 — 뒷말 예측, 정답 비교, 파라미터 조정 |
| 22 | LLM 추론 — 다음 토큰을 골라 붙이는 계산 반복 |
| 23~24 | Attention과 Transformer 계산을 자세히 보기 |

장면의 숫자와 후보는 설명용 예시입니다. 5~9장은 실습 1과 같은 예시 데이터를 사용합니다. CNN·RNN·Transformer의 입력과 계산 방식은 달라도, 정답과 예측을 비교해 loss를 줄이는 학습 원리는 이어집니다.

## 이번 주에 반드시 남길 한 문장
**LLM은 텍스트를 만들고, 프로그램(하네스)은 그 텍스트를 행동으로 연결한다.**

LLM이 "메일을 보냈습니다"라고 써도 메일이 간 것은 아닙니다. 약속한 양식으로 쓴 요청서를 프로그램이 읽고 실행해야 실제 일이 됩니다. 이 내용을 3주차의 CLI·Shell·SSH로 연결합니다.
