# DAL 2주차 강의 자료

대상은 개발 경험이 없는 사무직 직원입니다. 수식과 코드 없이 세 가지 질문을 순서대로 풉니다.

1. **AI 모델이란 무엇인가** — 입력을 출력으로 바꾸는 상자, y = f(x)와 loss, 모델 종류별 입력과 출력, 학습과 사용(추론)의 차이
2. **LLM은 왜 Text to Text 모델인가** — 다음에 올 말 맞히기, 문맥, 토큰, 한 조각씩 이어 쓰기, 그럴듯함과 사실의 차이
3. **글만 쓰는 LLM이 어떻게 일을 하게 되는가** — 프로그램(하네스), 도구 목록, 정해진 양식의 요청서, 결과 되돌려 주기, Agent, 확인과 권한

## 시작
상위 폴더의 `../week2.html`을 브라우저에서 엽니다.

- 방향키 / PageUp·PageDown: 이전·다음
- O: 목차 / F: 전체 화면 / Home·End: 처음·마지막
- R: 지금 슬라이드의 학습·추론 장면을 처음부터 다시 재생
- E: 배치 편집 (요소 이동, 글자 더블클릭 수정)
- 슬라이드 1~34: 본 수업 / 35~38: 선택 부록과 출처

## 학습·추론 장면
모델 안에서 일어나는 일을 움직이는 그림으로 보여 주는 슬라이드가 여섯 장 있습니다. 슬라이드를 열면 자동으로 재생되고, 장면 안의 **처음부터 / 일시정지** 버튼으로 조작합니다.

| 슬라이드 | 장면 |
|---|---|
| 10 | 학습할 때 일어나는 일 (linear regression) — 예측 → 정답과 비교 → 숫자를 조금 고침을 반복하며 직선이 점들에 맞아 감 |
| 11 | 사용(추론)할 때 일어나는 일 (linear regression) — 숫자는 고정한 채 새 입력의 결과만 계산 |
| 13 | LLM이 학습할 때 일어나는 일 — 뒷말을 가리고 예측, 정답과 비교, 정답 쪽 가능성이 올라감 |
| 16 | LLM이 답을 쓸 때(추론) 일어나는 일 — 후보 계산 → 하나 고르기 → 붙이기를 반복 |
| 17 | Attention — 다음 말을 고를 때 앞의 말마다 얼마나 참고했는지를 선의 굵기와 비중(%)으로 표시. 예문 네 개가 차례로 나옴 |
| 18 | Transformer를 한 장으로 — 토큰으로 나누기 → 숫자로 바꾸기 → 여러 겹(Attention + 계산) → 다음 말의 가능성 → 하나 골라 붙이기가 차례로 켜지고, 붙인 글이 다시 처음으로 돌아감 |

장면의 숫자와 후보는 설명용 예시입니다. 10·11번은 실습 1과 같은 예시 데이터를 실제로 계산해 그립니다. 5번 슬라이드에서 y = f(x)와 loss를 먼저 소개하고, 모델 종류(표 예측·이미지·글)를 본 뒤에 이 장면으로 들어갑니다.

## 이번 주에 반드시 남길 한 문장
**LLM은 텍스트를 만들고, 프로그램(하네스)은 그 텍스트를 행동으로 연결한다.**

LLM이 "메일을 보냈습니다"라고 써도 메일이 간 것은 아닙니다. 약속한 양식으로 쓴 요청서를 프로그램이 읽고 실행해야 실제 일이 됩니다. 이 내용을 3주차의 CLI·Shell·SSH로 연결합니다.
