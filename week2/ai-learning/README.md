## 이번 주 반드시 이해할 차이

**LLM은 외부 프로그램의 실행 엔진이 아닙니다.** LLM이 `ls -la`라는 문자열을 생성해도 파일 목록이 조회된 것은 아닙니다. 모델 추론은 학습된 파라미터로 다음 출력을 계산하는 과정이며, 파일 접근·프로그램 실행에는 별도 실행 도구와 권한이 필요합니다.

수업 마무리 질문: **"LLM은 Text to Text 모델인데 어떻게 문서를 쓰고 프로그램을 조작할까요?"**

이 질문을 3주차의 CLI·Shell·SSH로 연결합니다. 4주차에는 업무 데이터를 CRUD·API로 제공하고 6~8주차에 도구·Skill로 연결합니다.

## 강의의 중심
AI 모델의 입력·출력과 학습·추론을 먼저 구분합니다. 선형회귀와 CNN은 모델의 공통 원리를 확인하는 짧은 보조 사례로 사용합니다.

중심 내용은 Transformer입니다. 언어의 뜻이 문맥과 관계에서 달라진다는 관점에서 토큰, 임베딩, Attention, 다음 토큰 예측을 이론적이되 쉬운 문장 예제로 설명합니다. 결론은 **LLM은 텍스트를 입력받아 텍스트를 만드는 모델**이라는 것입니다.

LLM이 만든 문서 내용·코드·도구 호출 요청을 실제 파일 저장과 프로그램 실행으로 연결하는 주체는 응용 프로그램입니다. Agent는 LLM에 지시사항, 도구, 실행 반복, 권한을 연결한 시스템으로 설명합니다.
