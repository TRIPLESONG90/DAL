# DAL 2주차 강의 자료

대상은 개발 경험이 없는 사무직 직원입니다. **모델은 어떻게 배우고 예측하며, 그 예측은 어떻게 실제 실행으로 이어질까?**라는 질문을 따라갑니다.

선형회귀에서 데이터·모델 설계·loss·학습·추론을 익힌 뒤, 이미지에는 CNN, 순서가 있는 문장에는 RNN을 적용합니다. 이어서 LLM의 다음 토큰 예측과 Transformer의 계산을 보고, 지난주 재고관리 Agent로 돌아옵니다.

## 문장 표현

1주차 강의안의 문장 형식을 따릅니다. 제목·소제목은 짧은 주제명과 명사형으로, 설명 문장은 `~합니다`·`~입니다`로 작성합니다. 표·도식·실습 단계는 `입력값 확인`·`가중치 수정`처럼 명사형이나 동작 요약으로 통일합니다. 요청 예시와 출력 예시는 실제 대화 문장을 유지합니다.

## 시각화 보는 법

입력 사진과 문장은 익숙한 모습으로, 은닉층의 특징은 텐서로 표시합니다. **특징 텐서는 계산 결과이고, 가중치는 학습으로 수정하는 값**입니다.

- 순전파에서는 원이 입력에서 출력 쪽으로 이동합니다.
- 역전파에서는 원이 출력층에서 앞의 은닉층 쪽으로 이동합니다.
- 가중치 수정에서는 숫자만 바뀝니다. 예측과 loss는 다음 순전파에서 갱신됩니다.
- 추론에서는 가중치를 고정하고 새 입력의 결과를 계산합니다.

4~8장은 실습 1과 같은 문서 처리 데이터를 사용합니다. 5장에서 기울기 w와 y절편 b를 움직이고, 6장에서 점을 눌러 오차를 확인합니다. 9장은 학습과 추론에서 바뀌는 값을 나란히 비교합니다.

13장은 축소한 사진 한 장을 처리하는 작은 CNN에서 합성곱·역전파·가중치 수정을 직접 계산합니다. 자동 재생하거나 **다음 단계**로 천천히 진행할 수 있으며, 필터의 개별 숫자는 보조 설명을 펼쳐 확인합니다. 같은 사진을 6회 학습하는 과정의 예제이며, 실제 이미지 분류 모델은 다양한 사진으로 학습합니다.

17장은 문제에 맞는 가정을 구조에 담는 Inductive bias와 데이터로 가중치를 배우는 과정을 정리합니다. 18장의 토큰부터 19장의 Attention, 20장의 Transformer 전체 계산, 21~22장의 학습과 생성으로 이어집니다. LLM은 추론할 때 고정한 가중치로 다음 토큰의 확률을 계산합니다.

장면의 문장과 후보 확률은 설명용 예시입니다. 13장의 작은 CNN 수치는 연결된 계산에서 나오며, 4~8장의 선형회귀는 실습과 같은 데이터를 사용합니다.

## 실습 환경

1주차에서 설치한 **VS Code · Git · Python · Hermes Desktop**을 사용합니다. 실습 2의 실제 모델 실행에는 사내망/VPN과 서버 응답 확인이 필요합니다. 연결이 어려우면 오프라인 예제로 진행합니다. 실습 3에서는 도구 호출과 실제 파일 저장을 구분해 기록합니다.
