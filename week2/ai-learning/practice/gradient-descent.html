실습 1. 모델은 숫자를 맞추며 배운다 — 데이터에 맞는 직선 찾기

금형 사용 횟수(x)로 마모량(y)을 예측하는 모델 y = f(x) = w·x + b입니다. 점들에 맞는 w(기울기)와 b(시작값)를 찾는 것이 학습입니다. (예시 데이터)

데이터와 직선

기울기 w0
시작값 b0
loss (틀린 정도)0
학습 걸음0

LOSS 변화

1. 손으로 맞춰 보기

빨간 점선이 정답과 예측의 차이입니다. 이 차이를 모두 모은 숫자가 loss입니다. loss가 가장 작아지는 w, b를 찾아보세요.

2. 자동 학습에 맡기기

  1. 학습률 0.01로 자동 학습 → loss가 줄어드는지
  2. 학습률을 가장 작게 → 아주 느린지
  3. 학습률 0.035 이상 → loss가 튕겨 커지는지

3. 새 입력 넣어 보기 (추론)

마모량 예측 y = w·x + b0
x를 바꿔도 w와 b는 그대로입니다. 이미 맞춘 숫자로 계산만 합니다. 이것이 추론입니다.
